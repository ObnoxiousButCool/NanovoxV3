What can we say about an agent yet?

At batch 1 an agent has a handful of calls, so no rate on this page is a performance measure. What is attributable at this volume is events — a disclosure that was missed, a published rule stated wrongly, an escalation that was warranted and not given. Those are incidents, not estimates, and one is one.

Agents with at least one event, worst first. A compliance exception is a breach, not a rate — it either happened on that call or it did not, so it is attributable however few calls the agent has. Click a row for the calls.

The roster, and how far the corpus is from it

referenceobserved

The band, the designed call volume and the expected mean score are the workbook's. Calls written and events are ours. Observed quality is withheld per agent until the coverage bar is full — the roster sets the bar at 30 calls, not us.

This table cannot discover an underperformer, and it is important to know why. The roster was written first, with a designed band, an expected score and a dominant pattern for each agent — and the calls were then authored to match. So when the agent whose designed pattern reads “disclosure lapses” turns out to have disclosure lapses, that is the corpus agreeing with its own specification, not a finding. It is the same circularity as scoring an account on the churn profile it was generated from. What the page does prove is that the pipeline attributes conduct events to the right agent, which is what has to work before real calls arrive.

Are the low scores explained by harder calls?

inference

The first objection to any quality gap is that the lower-scoring group was handed the harder work. That objection is testable here, because every call carries a complexity band, a caller type and a talk time.

Training problem, or documentation problem?

inference

A rule one agent gets wrong is probably training. The same rule misstated by more than one agent — especially across bands — points at the rule's own wording instead.

Whether conduct events are spread across the quarter or bunched in one stretch changes what they mean — and whether the shape can be trusted at all.

By band

observed

Grouping recovers the sample an individual agent does not have. A band pools thirty-odd calls, which clears the five-call floor the rest of the cockpit uses — so a band average is publishable where an agent average is not.

The one trigger rule that watches agents

inference

Rule 9 of the workbook's trigger set is the only one scoped to an individual, and it is scoped to conduct rather than to quality — which is the same distinction this page is built on.
